# NeonMouse

Приложение для управления RGB-подсветкой игровых мышей. Работает с мышью напрямую по USB: Razer Synapse, Logitech G Hub и OpenRGB не нужны.

## Быстрый старт (Windows)
1. Установите Python 3.10 или новее с python.org. При установке отметьте **Add Python to PATH**.
2. Дважды щёлкните **`run.bat`**. Он сам установит зависимости и запустит программу.
3. Если нужен отдельный `.exe`, запустите **`build_windows.bat`**. Готовый файл появится в `dist\NeonMouse.exe`.

Важно: перед запуском закройте **Razer Synapse**, **Logitech G Hub** и **Bloody7**. Иначе они перехватывают управление подсветкой.

## Linux / macOS
```bash
pip install -r requirements.txt
python3 main.py
```
На Linux один раз установите правило доступа к USB:
```bash
sudo cp linux/99-neonmouse.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger
```

## Возможности
- **Вкл/выкл с плавным затуханием**: кнопкой или `Ctrl+Shift+L`.
- **9 эффектов**: статичный, дыхание, радуга, волна, стробоскоп, переход двух цветов, огонь, полиция, звёзды. Следующий эффект — `Ctrl+Shift+E`.
- **Цветовое колесо** и 12 готовых цветов. Нажмите в центр колеса, чтобы задать точный цвет.
- **Свой цвет для каждой зоны**: колёсико, логотип, боковые полосы.
- **Яркость и скорость** эффекта. Яркость также меняется клавишами `Ctrl+Shift+↑/↓`.
- **Несколько мышей сразу**: у каждой свои настройки, плюс режим «Все устройства».
- **Профили**: сохранение, применение и удаление.
- **Запись в память мыши**: статичный цвет сохраняется автоматически, и мышь светится так же без программы.
- **Горячее подключение**: мышь вставили или вынули, и программа сама её переподключит.
- **Диагностика**: подробный отчёт, если мышь не определилась.
- **Демо-режим** без мыши.

Глобальные горячие клавиши (работают, когда окно свёрнуто) включаются пакетом `keyboard`: `pip install keyboard`.

## Поддерживаемые мыши
| Бренд | Как определяется |
|---|---|
| **Razer** | Протокол Chroma. DeathAdder V2 / V2 Pro / V2 Mini, Basilisk / V2 / V3 / V3 Pro / Ultimate, Viper / Ultimate / Mini / 8KHz, Naga Pro, Mamba Elite. Остальные мыши Razer с Chroma пробуются автоматически: программа сама подбирает протокол и находит зоны. |
| **Bloody (A4Tech)** | Прямой режим подсветки. **V8M MAX**, W60 Pro, W70 Max, W90 Max / Pro, W95 Max. Другие RGB-мыши Bloody определяются автоматически. Цвет держится до переподключения мыши, в её память не записывается. |
| **Logitech** | HID++ 2.0 (0x8070). Мышь сама сообщает свои зоны. Обычно это G303, G403 Hero, G502 Hero / Lightspeed, G703, G903, G Pro Wireless. Работает и по проводу, и через приёмник Lightspeed. |

Мыши SteelSeries, Corsair, HyperX, ASUS ROG, Roccat, Glorious и новые Logitech с протоколом 0x8071 программа находит и показывает как «пока не поддерживается».

## Консольный режим
```bash
python main.py --scan                          # найти мыши
python main.py --color ff0055                  # цвет всем мышам
python main.py --color 00ff00 --brightness 40
python main.py --off                           # выключить подсветку
```

## Надёжность
- Все обращения к USB идут через один замок и обёрнуты в обработку ошибок. Сбой мыши приложение не роняет.
- Каждая команда проверяется по ответу мыши: статус у Razer, подтверждение у Logitech.
- Одинаковые кадры повторно не отправляются. Частота кадров ограничена отдельно для каждой модели: беспроводные получают кадры реже.
- Анимации не записываются во флеш-память мыши, туда сохраняется только итоговый статичный цвет.
- Повреждённый файл настроек (`~/.neonmouse.json`) заменяется значениями по умолчанию.
- Тесты на эмуляторах мышей: `python -m unittest discover tests`.

## Как добавить новый бренд
Создайте в `neonmouse/devices.py` класс-наследник `Mouse` с методом `_write(colors, save, live)` и добавьте его вызов в `scan()`.
